## 1. `@RandInt` = `sub_403B4C`（独立复核）

```
00403B4C  53                             push ebx
00403B4D  31 DB                          xor  ebx, ebx
00403B4F  69 93 08 20 7A 00 05 84 08 08  imul edx, [ebx+0x7A2008], 0x08088405
00403B59  42                             inc  edx
00403B5A  89 93 08 20 7A 00              mov  [ebx+0x7A2008], edx
00403B60  F7 E2                          mul  edx          ; 无符号 32×32→64，EAX=bound
```

无 `test`/`cmp`/`jle`。`n` 以 UInt32 位模式参与 `mul`：

| `Random(int.MinValue)` | 大数，不抛 | 推进 1 次 |

C# `DelphiRandom.Random`（`(uint)range * nextSeed >> 32`）已逐位等价。**FAITHFUL，无需改公式。**

## 2. `n<=0` 第二层敞口：`GetRandomRange`（已修）

原生 `sub_4C707C` @`0x4C707C`：

```
4C708C  4B              dec ebx
4C708F  7C 12           jl  return 0     ; 只在 nCount<=0 早退
4C7094  E8 B3 CA F3 FF  call 0x403B4C    ; Random(nRate)，不测 nRate
```

C# `GoodItem.GetRandomRange` 原先 `if (nRate<=0) return 0`：
- `nRate==0`：原生循环 nCount 次、每次 `Random(0)==0`，结果 = nCount；C# 返回 0 且 0 次抽签。
- `nRate<0`：原生仍抽 nCount 次；C# 0 次。

已删掉该早退，与 `4C707C` 对齐。`nCount<=0` 的 for 循环本身就是 0 次，与 `dec/jl` 一致。

### 5.3 命中/闪避 — FAITHFUL（前人报告地址是错的）

`staging/hit_rate_formula_report_20260813.md` 把 `0x71D974 call 0x4054B8` 写成 Random。
`0x4054B8` 是 8 字节分配器（`mov eax,8 / call 0x402FA0`），全镜像 **0** 个 E8 调用者。

真实命中：

内联（主近战，`0x666CB2` / `0x71D990` / `0x76A92D` 等）：

```
666CB2  0F B7 86 66 02 00 00  movzx eax, word [esi+0x266]   ; 目标敏捷
666CB9  E8 8E CE D9 FF        call  0x403B4C                 ; Random
666CBE  0F B7 97 64 02 00 00  movzx edx, word [edi+0x264]   ; 攻击方准确
666CC5  3B C2                 cmp eax, edx
666CC7  0F 8D 87 00 00 00     jge  miss
```

包装 `sub_772578`（9 个技能调用点，EAX=目标，EDX=攻击方 +0x264）：

```
772581  0F B7 83 66 02 00 00  movzx eax, word [ebx+0x266]
772588  E8 BF 15 C9 FF        call  0x403B4C
77258D  3B F0                 cmp esi, eax
77258F  0F 9E C0              setle al          ; True = 未命中
```

公式：`Random(target+0x266) < attacker+0x264`。C# `Random(m_wSpeedPoint) < m_btHitPoint` 同形，1 次抽签。`SpeedPoint==0` 时 `Random(0)=0`，`0 < HitPoint` 即 HitPoint>0 必中，两边一致。

### 5.4 装备随机属性 — 修前 DIVERGENT，已按 +0x28 覆盖落地
