**ECON-36 — opcode 1018 落默认落槽（原生 no-op）** → **FAITHFUL**
- `CM_LOGINNOTICEOK=1018`（`Grobal2.cs:327`）在 `TPlayObject.Message.cs:1301-1308` 为显式空 case，注释记录原生路由到默认处理器 `0x6DBC2C`（清理型，无消息逻辑）。

**ECON-37 — 商业分发以 `word[rec+4]` 为键、上界 `0xCD6`、`byte[obj+0xA00]` 非零时整体跳过** → **FAITHFUL（分发语义）+ 1 诚实保留**

- 上界：原生 `0x6D8063 cmp eax,0xCD6 / 0x6D8068 jg`；C# switch 对越界/未知 opcode 落 default（no-op），等价于 bound+sink。
- 忙碌门 `[obj+0xA00]`：原生 `0x6D7E4F cmp byte[eax+0xa00],0 / je`；该门为玩家布尔（setter `0x6E73F0`=1 / clearer `0x6E73F8`=0，clearer 亦见 `0x6AD91A`），置位时门禁**全部**客户端命令。本轮已在二进制定位其读/写点，但**未钉到具体 C# 字段**；因其为统一入口门（对所有 opcode 一致、非资金专属、INTERNAL），未作改动，如实标注见 §4。

**ECON-38 — 哪个 opcode 触发买/卖/修未在原生 case body 建立** → **BLOCKED（尊重契约）；C# 侧已确定**
- 契约因 `0x6D8E52..0x6D924A` 未反汇编而 BLOCKED。C# 侧映射明确：`CM_USERSELLITEM=1013`→`ClientSellItem`、`CM_USERBUYITEM=1014`→`ClientBuyItem`、`CM_USERREPAIRITEM=1023`→`ClientRepairItem`、`CM_MERCHANTDLGSELECT=1011`（`Message.cs:1273-1287`,`1351`）。原生 case body 未取证，故原契约维持 BLOCKED，不臆断二进制侧。

**ECON-39 — 卖出体内无背包移除调用，移除在 caller** → **BLOCKED（原生取证不全）；C# 侧 FAITHFUL**
- 原生 `0x63F200` 体内确无移除，契约预言移除在 caller `0x6401B0`。C# 忠实同构：`ClientSellItem` 只把物品加入商人货表（`AddItemToGoodsList`），背包移除在**调用方** `ClientUserSellItem` `TPlayObject.Operate.cs:254`（`ClientSellItem` 返回 true 后 `m_ItemList.RemoveAt(i)`）。物品守恒成立。

**ECON-40 — 修理/超修/SRepair 体从未取证** → **BLOCKED（尊重契约）；已被 PRICE-20/21 SUPERSEDE，C# 有实现**

### 2.2 PRICE（物品价格 VMT slot `[itemVMT+0x20]`）

> C# 将原生三实体（TBaseItem `sub_783D70`、TMeatItem `sub_786208`、TOreItem `sub_7862B4`）按 StdMode 折叠进 `Merchant.GetUserItemPrice`（`Merchant.cs:1652-1857`）。基体 `sub_783D70` 已对底本完整反汇编（`0x783D70-0x783EF3`）。

**PRICE-01 — slot +0x20 恰 3 个实现，其余 144 类继承基体** → **FAITHFUL（等价替换）**
- `NativeItemFactory.cs:180-185`：StdMode 40→`TMeatItem`、43→`TOreItem`，其余落基类族。StdMode↔类为双射，仅 40/43 特化，其余走基体。C# `GetUserItemPrice` 恰只对 40/43 加分支，等价于原生"仅两 override"。

**PRICE-02 — 必须按物品对象类派发，价三值非单一参数化** → **FAITHFUL（以 StdMode 作类判别）**
- 原生 `0x63F3A7 mov ecx,[eax] / 0x63F3A9 call [ecx+0x20]` 虚派发；C# 以 StdMode 派发（工厂保证 StdMode 唯一决定类），三值分立。

**PRICE-03 — 价依赖活耐久：读实例 +0x28(liveMax)、+0x26(cur)** → **FAITHFUL**
- 基体 `0x783D7D movzx esi,word[ebx+0x28]` / `0x783D81 movzx eax,word[ebx+0x26]`。C# 用 `UserItem.DuraMax`(=+0x28) / `UserItem.Dura`(=+0x26)。

**PRICE-04 — liveMax<=0 或 cur<=0 或模板 StdMode<=4 时原价返回** → **FAITHFUL**
- 基体三门 `0x783D88 test esi/jle`、`0x783D90 cmp[ebp-4],0/jle`、`0x783D9D cmp byte[eax+0x14],4/jbe`（→`0x783EEB mov eax,edi;ret`）。C# 门 `Merchant.cs:1714`：`StdMode>4 && UserItem.DuraMax>0 && UserItem.Dura>0`（另含 PRICE-12 安全门）。

**PRICE-05 — 属性加成对实例 +0x2A..+0x31 共 8 字节，经有界 8 项跳表** → **FAITHFUL**
- 跳表 `0x783DFC jmp [ecx*4+0x783E03]`，8 case 各 `movzx byte[edx+0x0A+i]`（edx=ebx+0x20 → ebx+0x2A+i），循环 `0x783E6A cmp eax,8`。C# 循环 `nC=0..7` 累加 `btValue[nC]`（`Merchant.cs:1793-1821`）。

**PRICE-06 — StdMode 5/6：index 4 零贡献；index 6 用 v>10⇒(v-10)*2 否则 v** → **FIXED（本轮补缺，提交 `81981f6a`）**
- 底本铁证 `sub_783D70`：
  - `0x783DCF cmp dl,0x0A / 0x783DD2 jbe 0x783DE7`（v<=10 → 明文臂）
  - v>10 臂 `0x783DD4 and edx,0xFF / 0x783DDA sub edx,0x0A / 0x783DDD add edx,edx / 0x783DDF add[ebp-8],edx`（(v-10)*2）
  - 明文臂 `0x783DE7 and edx,0xFF / 0x783DED add[ebp-8],edx`（**accum += v**）
- **缺口**：原 C# `if (nC==6){ if(v>10){accum+=(v-10)*2;} }` **缺 `else` 臂**，v<=10（武器绝大多数属性常态）时对 accum 零贡献，经 `n10 += (n10/5)*accum` 传导，系统性压低武器（StdMode 5/6 = TLWeapon/TSpade/TBrokenWeapon）买/卖/修三路报价。
- **修复**：补 `else { n14 = n14 + UserItem.btValue[nC]; }`（`Merchant.cs:1805-1823`，附 Tier-1 反汇编注释）。属外科式、资金域但非交易成交安全/网关帧，附证据修复。

**PRICE-07 — 属性项 price += (price div 5)*accum，仅 accum>0，signed 截断 idiv + 单操作数 imul** → **FAITHFUL**
- `0x783E73 cmp[ebp-8],0/jle`、`0x783E7B mov ecx,5/cdq/idiv`、`0x783E83 imul dword[ebp-8]`、`0x783E86 add edi,eax`。C# `Merchant.cs:1847`：`n10 = n10 + (double)((int)n10 / 5 * n14)`（显式 (int) 截断复刻 idiv）。

**PRICE-08 — A 阶段按 liveMax/模板max 缩放：ROUND(price / word模板[+0x1C] * liveMax)** → **FAITHFUL**
- `0x783E8E mov eax,[ebx+0x1C] / 0x783E91 movzx eax,word[eax+0x1C]`（模板 max）、`0x783E9B fdivp`、`0x783EA3 fmulp`（*esi=liveMax）、`0x783EA5 call ROUND(0x403574)`。C# `:1849`：`Round(n10 / StdItem.DuraMax * UserItem.DuraMax)`。

**PRICE-09 — B 阶段磨损项以 DOUBLE 精度：ROUND(p − (p/2.0/liveMax*(liveMax−cur)))** → **FAITHFUL**
- `0x783EB2 fdiv [0x783EF4]=2.0f`、`0x783EBE fdivp`、`0x783EC0 sub esi,[ebp-4]`(liveMax−cur)、`0x783EC9 fmulp`、`0x783ECB fstp qword`（截断为 double）、`0x783ED5 fsub qword`、`0x783ED8 call ROUND`。C# `:1850-1851`：`n20 = n10/2.0/DuraMax*(DuraMax−Dura); n10 = _MAX(2, Round(n10−n20))`（n20 为 double 局部，对应 fstp qword）。

**PRICE-10 — 基体末价下限钳 2** → **FAITHFUL**
- `0x783EDF mov eax,2 / 0x783EE4 call 0x4C7004`（max(eax,edx)）。C# `HUtil32._MAX(2, ...)`（`:1851`）。

**PRICE-11 — 全磨损失价至多一半，全新磨损项为零** → **FAITHFUL（公式性质）**
- 由 `0x783EC0 sub esi,[ebp-4]` 在 cur==liveMax 时为 0（磨损项 0）、`/2.0` 因子上界半价 得出。C# 公式同构自然满足。

**PRICE-12 — A 阶段除以 word模板[+0x1C] 前无零守卫** → **FAITHFUL（含有意 fail-closed 偏离）**
- 原生 `0x783E9B fdivp` 前无零检查，模板 max==0 会抛 EZeroDivide（Delphi 默认未屏蔽 x87 ZeroDivide）。C# 于门中加 `StdItem.DuraMax > 0`（`Merchant.cs:1714`），零模板 max 时静默返回原价——方向更安全但非逐字等价，零模板 max 可达性 UNPROVEN。台账已钉死"勿当新 bug 删除"，本轮保留。
