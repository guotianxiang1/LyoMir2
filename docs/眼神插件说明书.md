### 2.2 `version.ini` 的硬性格式 [2.08 实机]

`version.ini` 不是普通的 INI 节文件。它必须恰好包含 DLL 文件名：

```text
yanshen2.0.8.dll
```

当前实机文件是精确的 16 个 ASCII 字节，末尾没有 CR/LF、空格、引号或 BOM。出现“请检查 ys 文件夹中 [version.ini] 保存的版本是否存在或损坏”时，逐项检查：

1. `version.ini` 位于 `Gs1\ys`，不是 `Gs1` 根目录。
2. 文件内容与 DLL 文件名逐字节一致。
3. DLL 确实位于同一个 `ys` 目录。
4. 不要把 `yanshen2.0.7.dll` 或旧包的 `version.ini` 混入 2.08。
5. `libmysql.dll` 与 `libmysqls.dll` 均存在；缺库会在插件初始化前失败。

可用 PowerShell 自检：

```powershell
$ys = 'D:\赤焰武易\Mud2.0\Mir200\Gs1\ys'
$name = [Text.Encoding]::ASCII.GetString(
  [IO.File]::ReadAllBytes((Join-Path $ys 'version.ini')))
$name
Test-Path -LiteralPath (Join-Path $ys $name)
Get-ChildItem -LiteralPath $ys
```

期望输出 DLL 名，并且 `Test-Path` 为 `True`。

### 5.3 全局循环函数 [说明书]

`Ys_SetTimerByName(Player, timer, fucName)` 用于周期调用 `RunQuest.pas` 中的无参数函数：

- 最快间隔为 500 ms。
- `timer=0` 清理同名定时器。
- `fucName='ClearAll'` 用于清理全部定时器。
- 需要同时启用“眼神特殊函数”。

## 7. 关键功能操作说明

### 7.1 全屏拾取

- 服务端开关：启用“全屏拾取”。
- 脚本入口：`ys_pick(Player, round, v1, gbv, ismy)`。
- `round` 是范围；`ismy` 用于限制只拾取自己的物品；`v1/gbv` 的准确门控仍需 2.08 验收。
- 在线页另有客户端补丁教程。未安装配套客户端时，服务端逻辑即使执行也可能没有完整交互或显示。
- 必测：超范围、非本人掉落、背包满、重量不足、地面对象已被他人取走、堆叠物品和掉落归属时效。

### 7.2 新版切割

- 新旧切割不能同时打开，否则说明书称伤害会叠加。
- 至少分别测试人物、英雄、怪物目标，以及百分比和固定伤害两条路径。
- 触发脚本必须在开关开启时才调用；大量怪物场景要测性能和脚本异常隔离。
- 切割伤害是否参与反伤由“切割也反伤”开关决定；火墙反伤另受“火墙不反伤”控制。

### 7.3 自定义伤害与技能弹射

- `ys_MyJn_*` 系列用于范围、属性、切割、特效、不死族加成、技能/攻击 ID、倍数和延迟组合。
- `Ys_TanTanSkill` 可给原生技能设置弹射或溅射；说明书建议范围不要过大。
- 设定在服务器重启前持续生效。复刻应明确生命周期，并测试重载配置是否清除。

### 7.4 高级回收

- `Ys_HuiShou()` 返回 `-999` 时表示配置语法错误。
- 要求原子处理：解析失败不能先删物品再报错；成功时物品、金币/货币、日志和提示只执行一次。

### 7.5 指定英雄技能

- `Ys_SetHeroCSkill(Player, magicid, isrun)`。
- 说明书称仅支持法师、道士技能。
- `isrun=0` 当前释放一次；`isrun=1` 持续释放。
- “英雄不自动释放技能”属于定制开关，不能作为通用 2.08 默认行为。

- `ys_SetYs`: `pis=0..15`，`pid=1..17`；仅 `pid=1` 允许最大 21 亿，`pid=2..17` 最大 255；返回 `0` 表示无效，其他值为写入元素值。
- `ys_pick`: `round` 最大半径 20；当 `GetV(v1,物品数据库 ID) == gbv` 时跳过该物品；`ismy=1` 只拾取自己击杀掉落；返回拾取数量。使用时还需启用“眼神特殊函数”、“全屏拾取”并设置 S61。

- `ys_GetMember`: `ID=1` 为队长，`2` 为第二名成员，返回成员 `TPlayer`。
