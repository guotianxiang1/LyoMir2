**POIS-18　FAITHFUL**（原 UNKNOWN）。自然回血 = MaxHP/75+1、钳到 MaxHP：`0x76B789 mov eax,[esi+0x2B0]` /

**POIS-19　FAITHFUL**（原 UNKNOWN）。毒 tick 可把 HP 精确打到 0、dmg==HP 亦致死、HP 永不写负：

**POIS-20　FAITHFUL**（原已 FAITHFUL，`TBaseObject.Base.cs:704`）。毒路径不带攻击者身份：`0x76BDFB mov edi,[rec+0xA] / inc edi`（dmg=Value+1）、
`0x76BE06 mov edx,edi / mov eax,esi / call [ecx+0x1B0]`——applier 仅收 eax=self、edx=dmg。C# `DamageHealth(nNativePoisonDamage)` 单参无攻击者。
