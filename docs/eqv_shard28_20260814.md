### 收金原语 sub_65B31C（= `IncRateGold`）
逐字反汇编：
```
0x65B322 mov esi,edx        ; edx=nAmount
0x65B324 mov ebx,eax        ; eax=Self；ecx 仅 push 占 [ebp-4] 用于 fild
0x65B329 fild [ebp-4] / 0x65B32C fld tbyte[0x65B39C] / 0x65B332 fmulp   ; *税率常量
0x65B334 call 0x403574 (Round, fistp round-to-even)
0x65B339 edx=[ebx+0x84]     ; today income(+0x84)
0x65B343 cmp ecx,0x1e8480 / jg   ; today+credit vs 2,000,000
0x65B34B add [ebx+0x84],eax      ; <=cap: today += credit
0x65B353 cmp edx,0x1e8480 / jl / xor eax / mov eax,0x1e8480-edx / mov [ebx+0x84]=0x1e8480 ; 夹紧存 headroom
0x65B370 test eax / jle          ; credit>0?
0x65B37C cmp edx,0x5f5e100 / jge ; total+credit vs 100,000,000
```

- **CGLD-07** FAITHFUL：仅实际入 +0x84 的额度镜像到 +0x80，为零时跳过。C# `if (nInGold > 0) { ... }`。
- **CGLD-14** FAITHFUL：+0x84 无任何借记，唯一非信用写为日结算清零。日结算 sub_65BB44 @0x65BBA7 `xor eax,eax`/@0x65BBA9 `mov [ebx+0x84],eax`，守卫 `Trunc([ebx+0x78]) != Trunc(globalClock[0x7D6A88])`（0x403580 @TRUNC）。C# `Run` 于 `m_IncomeToday.Date != today` 时 `m_nTodayIncome = 0`。
