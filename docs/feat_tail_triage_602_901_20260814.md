| 典型误读 | 实际来源 |
|----------|----------|
| `[嬪]`、`Y]`、`^[嬪]` | `pop edi; pop esi; ret` 等尾声 |
| `U嬱兡` | `push ebp; mov ebp,esp` 序言 |
| `3蓧M` / `VW3` | 栈/setup 与 `push ebx/esi/edi` |
| `-的配置表` @ `0x004D9C30` | 代码内 **两个** 字符串拼接点（`0x4D9D14`+`0x4D9D2C`）被 census 截断；该函数为配置表遍历 + `0x79DF74` 日志，非玩法 |
