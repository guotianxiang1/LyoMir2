## 转交主代理的观察（本波未改 / 跨子系统）
1. **CRAFT-28 惰性 vs 入包即赋**：C# `EnsureClientItemId` 惰性分配，原生 sub_73CED0 于 AddUserItem 即写 item+0x18；两者皆每玩家单调，但从未推送客户端的物品在 C# 不占号，绝对序号可能与原生偏移。属 ClientItemID 子系统跨分片核对项，非本分片契约缺口。
2. **造物按名 vs 按索引**：原生主循环 0x63FF11 `movzx edx,word[MakeItem+0x24]` 取货架首件 stdIdx 造物(0x63FF1E `call 0x74C2FC`)；C# `CopyToUserItemFromName(sItemName)` 按名(OrdinalIgnoreCase)解析首个同名模板。同名唯一时等价；目录若存在重名异索引则可能取不同模板。属造物子系统细节，无对应 CRAFT 行契约。
3. **CRAFT-07 边缘**：3+ token 配方行(次段合法整数后仍有内容)原生取次 token、C# 对整余串解析→落默认1；MakeItem.txt「名 数」格式不可达该态，未改以免动解析器。
4. **CRAFT-21 成本字段**：C# 用恒 100 的 `nMakeDurgPrice` 配置字段(全仓无文件读入)等价原生内联 0x64；若将来接入 MakeDurgPrice 配置读取将偏离原生硬编码，需保持该字段不被 INI 覆盖。
