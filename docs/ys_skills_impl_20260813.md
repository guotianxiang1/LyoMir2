## 0. 机制（地基）

眼神改写 MagXXX 有三条路，本族用到前两条：

1. **memcpy / 立即数写宿主**（战士六条、召唤数量/名字、无极真气）。关 = 还原支写回的原字节。
2. **trampoline**（法师主属性/范围/系数、嗜血倍数、野蛮等级、带毒）。关 = 不安装，宿主指令原样跑。
3. Themida 虚拟化前半段赋值（**英雄野蛮**）→ 落全零区，永久不可判。

开关在内存里是随机数（开 → `rand()%1000+1000`，消费 `cmp …, 0x1F4` 即 `> 500`）。可观测契约：json `!= 0`。C# 用 `PatchToggleOn`，关时主干完全不受影响。

S 银行是哈希字典（GetS `0x6DF1B4` → `0x6E42CC` 打包键 → `0x6E4270` 查找）。打包键 = `group*1000+index`。trampoline **绕过包装器**直读 `[player+0x804]` 的插入序 pair 数组，先核对 packed key 再读 value。插件登录灌 `S(1,1..150)` 之后，C# `TryGetScriptVar('S',1,n)` 与 GetS 的玩家可见契约一致。VMT 门 `cmp [ebx], 0x6AC8C8` = **只对 TPlayObject**。

主属性统一编码（字节，不是文档声称）：

| S 值 | 取的字段 | 宿主偏移 |
|---|---|---|
| 100 | 道术 SC | `+0x29C / +0x2A0` |
| 200 | 攻击 DC | `+0x28C / +0x290` |
| 其它 / 未设 | 原属性（魔法 MC） | `+0x294 / +0x298` |

## 2. 四段链路（配置键 → 门控 → 站点 → 宿主行为）

统一形态：json 键 → `PatchToggleOn`（关=不安装）→ trampoline 替换 14/9/5/6 字节 → MagXXX 读 DC/MC/SC 或改 range/ecx。

消费端 `> 500` 不是阈值建模，只是编码中点。C# `Enabled()` / `PatchToggleOn` 的 `!= 0` 语义正确。

门控字段在页面对象 `this` 上（加载器把 json 重编码后写入），**不要**和 `0x19B8` 字节单例的同偏移撞车。本族使能函数在 `0x100D8810` / `0x100B1FC0` / `0x100A96C0`，以补丁臂回验为准。

关闭态：memcpy 还原支写回的就是原生默认（range=1/2/8、除数=10、MC 对、`Random(3)+1` 训练）。

## 6. 前人材料订正

1. `yanshen_svars_changelog` §1.6 把主属性/范围标成【文档声称】MISSING——trampoline 已给出 packed key，**坐标表是对的**，不再是文档声称。
2. 同节「激光命中概率 N=1/N」**与字节矛盾**：`0x76EA14` 是 `mov eax,3` 喂给随后的 `call @RandInt` / `inc ecx` / `call [vmt+0x3C]` TrainSkill。使能且 S 未设时落到 `mov eax,1`（恒训练 1 点），不是命中公式。
3. `ys_sw_a` 把嗜血/激光标 BLOCKED「只有 memcpy 还原」——缺的就是 §5.1.0.6 的 trampoline，现已解。
4. 冰咆哮范围 trampoline 重放了 `push 1; push 3`：`push 3` 是 dispatchCategory=AREA，**不是半径**。半径是 `push 1` 那个槽。与 `MagicManager` 里已有注释一致。
5. `武器绿毒` 与 `物功带毒` 打**同一宿主 VA `0x76E2BC`**。两个键同时开会叠两套 trampoline，后安装的覆盖先安装的。C# 若以后接线必须保持这一互斥，不能做成两个独立毒源。
6. `激光范围及系数` 的 S(1,81) 钩在 `0x76EA07 6A 01`（arg0），宿主真正的线跨度是更早的 `0x76E9FD 6A 08`。JSON 名「范围」与字节槽位不符，以字节为准。
